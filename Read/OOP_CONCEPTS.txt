3) POLYMORPHISM
--------------------------------------------------------------------

a) Subtype polymorphism via base-type collections
   - Lane stores List<Vehicle> ............ Lane.java:15  (and getter Lane.java:74)
   - Street.allVehicles() : List<Vehicle> .. Street.java:102
     (Car / EmergencyVehicle / PoliceVehicle are all handled as Vehicle)

b) Dynamic dispatch via base-type loops (the right override runs)
   - for (Vehicle vehicle : street.allVehicles()) vehicle.beginStep();
       ................................... Simulation.java:162-163
   - for (Vehicle vehicle : street.allVehicles()) vehicle.tickVisualMarkers();
       ................................... Simulation.java:1367-1368
     -> for a Car this runs Car's overridden tickVisualMarkers(); for other
        vehicles it runs the base Vehicle version.
   - move() resolves at runtime to Car.move() / EmergencyVehicle.move().

c) Interface polymorphism
   - halt(Movable) accepts ANY Movable .... Simulation.java:776

d) Runtime type checks (instanceof pattern matching) - behaviour by subtype
   - moveAllVehicles: if (v instanceof Car c) ... else if (v instanceof
       EmergencyVehicle e) ............... Simulation.java:551, 553
   - hasPoliceVehicle: loop with (vehicle instanceof PoliceVehicle) . Simulation.java:382
   - anyEmergencyOnStreet: loop with (vehicle instanceof EmergencyVehicle) Simulation.java:458
   - processEmergencyMovement: ev instanceof PoliceVehicle ? POLICE_SPEED
       : EMERGENCY_SPEED ................. Simulation.java:1128
   - GUI KPI counts: v instanceof Car / EmergencyVehicle / PoliceVehicle
       ................................... TrafficFxApp.java:439, 455
   - GUI markers + sprites by subtype ... StreetCanvasRenderer.java (instanceof
       blocks for PoliceVehicle / EmergencyVehicle / Car), FxVehicleImageCatalog
   - ParkingSpot.reserve guards owner type: if (!(owner instanceof Car))
       ................................... ParkingSpot.java:92

4) ENCAPSULATION  (supporting OOP principle)
--------------------------------------------------------------------
   - Model classes keep fields private and expose getters/setters.
   - Lane.getVehiclesInLane() and Street.getLanes()/getParkingSpots() return
     Collections.unmodifiableList(...) so callers cannot mutate the internals
     directly ............................ Lane.java:74, Street.java getLanes/getParkingSpots

--------------------------------------------------------------------
ONE-LINE SUMMARY FOR THE VIVA
--------------------------------------------------------------------
- Interface:    Movable (move/stop) + Reservable (reserve/release/isReserved).
- Inheritance:  Vehicle (abstract) -> Car, EmergencyVehicle -> PoliceVehicle.
- Polymorphism: List<Vehicle> base-type collections, dynamic dispatch when a
                loop calls vehicle.beginStep()/move()/tickVisualMarkers(),
                halt(Movable), and instanceof dispatch across the engine + GUI.
